Network Access
Fast and secure on-campus network access and secure access to restricted services from on or off-campus through virtual private networking (VPN).
Campus Wired Network
An extensive wired computing and communications network is available in academic, residential, and administrative buildings across campus.
CMU Wireless Network
The CMU Wireless Network provides secure wireless connectivity across all campus buildings and in many outdoor areas.
Virtual Private Network
Secure communications and the ability to extend local campus network access to offsite locations.
